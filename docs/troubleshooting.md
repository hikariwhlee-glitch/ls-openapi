# 문제 해결

오류 메시지에는 앱키, 시크릿키, 토큰 값이 출력되지 않도록 처리되어 있습니다. 질문을 올릴 때도 이 값들은 가려 주세요.

## 실행하자마자 `다음 설정이 없습니다`

`.env` 파일이 없거나 값이 비어 있습니다.

- 저장소 루트에서 `cp .env.example .env` 후 `LS_APP_KEY`, `LS_APP_SECRET`을 채웁니다.
- 예제는 **현재 폴더의 `.env`**를 읽습니다. 저장소 루트에서 실행했는지 확인하세요.
- 환경변수로 직접 설정해도 됩니다(환경변수가 `.env`보다 우선합니다).

## `예시 값(YOUR_...) 그대로입니다`

`.env.example`의 예시 값을 바꾸지 않았습니다. 발급받은 실제 값으로 바꿔 주세요.

## `.env`를 고쳤는데 반영되지 않는 것 같을 때

- 같은 이름의 환경변수가 이미 설정되어 있으면 그 값이 우선합니다. 터미널에서 `LS_APP_KEY`가 설정되어 있는지 확인하세요.
- 같은 줄 끝에 `# 주석`을 붙이면 값의 일부로 읽힙니다. 주석은 별도 줄에 쓰세요.

## `토큰 발급 요청에 실패했습니다 (네트워크 오류: ...)`

서버에 연결하지 못한 경우입니다.

- 인터넷 연결을 확인하세요.
- REST 서버 주소에 **8080 포트**가 포함됩니다(`https://openapi.ls-sec.co.kr:8080`). 회사나 학교 네트워크, 방화벽에서 해당 포트가 막혀 있지 않은지 확인하세요.
- `LS_BASE_URL`을 직접 지정했다면 오타가 없는지 확인하세요.
- `Timeout`이면 잠시 후 다시 시도하세요.

## `토큰 발급이 거절되었습니다 (HTTP 4xx)`

서버가 요청을 거절한 경우입니다. 서버가 보낸 메시지가 함께 출력됩니다.

- 앱키/시크릿키를 다시 확인하세요: 홈페이지 **고객센터 > 매매시스템 > API > 사용등록/해지**.
- 앱키와 시크릿키를 서로 바꿔 넣지 않았는지, 앞뒤 공백이 없는지 확인하세요.
- **실전투자 키와 모의투자 키는 별도로 발급**됩니다. 모의투자 키를 쓰는 경우의 REST 주소는 공식 자료로 확인되지 않았습니다([api-inventory.md](api-inventory.md)). 포털 안내를 확인하세요.
- 사용해지 후 재등록했다면 이전 키와 토큰은 더 이상 쓸 수 없습니다. 새 키로 바꾸세요.
- 구체적인 오류 코드의 의미는 이 저장소에서 확인되지 않았습니다. 공식 포털의 안내나 고객센터를 이용하세요.

## `토큰 응답에 access_token 이 없습니다` / `JSON 형식이 아닙니다`

서버가 예상과 다른 응답을 보냈습니다. 점검 중이거나 주소가 잘못되었을 수 있습니다.

- `LS_BASE_URL`이 비어 있는지(기본값 사용) 확인하세요.
- 계속되면 이 저장소의 Issue에 **키 값을 제외하고** 상황을 남겨 주세요.

## `pytest`가 `No module named ls_openapi`로 실패

`pip install -e ".[dev]"`를 하지 않았거나, 가상환경이 활성화되어 있지 않습니다. 저장소 루트에서 다시 설치하세요. (`pyproject.toml`에 `pythonpath = ["src"]`가 설정되어 있어 저장소 루트에서 `pytest`를 실행하면 대부분 동작합니다.)

## 키를 실수로 공개했을 때

1. LS증권 포털에서 해당 API를 **사용해지**하고 다시 신청해 새 키를 발급받습니다. 이때 기존 토큰은 만료됩니다.
2. Git 기록에 올라간 키는 파일을 지우는 것만으로 사라지지 않습니다. 이미 노출되었다고 보고 위 1번을 먼저 하세요.
