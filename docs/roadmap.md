# 로드맵

## 1차 MVP: 국내 선물·옵션 명세 수집·정리

- LS증권 공식 가이드 JSON을 다운로드한다.
- `선물/옵션` 카테고리에 속한 모든 API 그룹과 TR을 빠짐없이 선택한다.
- API 경로·프로토콜과 요청/응답 헤더·블록·필드·자료형·길이·설명·호출 제한 원문을 JSON 스냅샷에 보존한다.
- 사람이 검색하고 검토하기 쉽게 전체 명세 Markdown을 생성한다.
- 가이드 버전, 생성 시간, API 그룹 및 TR 수를 기록한다.
- 새 공식 버전에서 재생성해 변경사항을 검토할 수 있도록 동기화 스크립트를 제공한다.

현재 저장된 스냅샷은 가이드 버전 `20261012053652748` 기준으로 7개 API 그룹과 91개 TR을 포함한다. 공식 가이드가 바뀌면 숫자와 내용도 달라질 수 있다.

## 2차 MVP: 백테스터

명세 수집을 마친 뒤 백테스터를 별도 단계로 구현한다.

- 지원할 선물·옵션 상품과 과거 시세 데이터의 범위를 정한다.
- 공식 명세를 바탕으로 데이터 조회 어댑터와 공통 시계열 모델을 설계한다.
- 신호, 주문 시뮬레이션, 포지션 및 손익 계산을 API 인증과 분리한다.
- 상품 명세, 옵션 만기 정산, 거래 비용, 증거금, 선물 롤오버를 근거 자료와 함께 모델링한다.

실계좌 주문 자동화는 백테스터 범위와 구분한다.
