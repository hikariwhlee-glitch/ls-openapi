# 로드맵

## 1차 MVP: 공식 선물·옵션 샘플과 명세를 쉽게 찾기

- LS증권 OPEN API 국내 `선물/옵션` 전체 TR을 공식 페이지 카테고리와 연결한다.
- Python, Java, JavaScript로 제공되는 각 TR별 코드 샘플을 공식 페이지에서 바로 열 수 있게 인덱싱한다.
- TR 코드, 이름, 프로토콜, URL, 호출 제한, 공식 가이드 링크와 샘플 원본 데이터 링크를 제공한다.
- 요청·응답 필드 전체를 별도 JSON 및 읽기용 Markdown으로 보존한다.
- 공식 사이트가 바뀌면 인덱스와 명세를 다시 생성할 수 있게 동기화 스크립트를 둔다.
- 공식 코드 샘플의 재배포 조건이 확인되지 않아 원문 코드 전체를 복제하지 않고 출처 링크를 제공한다.

현재 스냅샷은 가이드 버전 `20261012053652748` 기준으로 7개 API 그룹과 91개 TR(REST 60개, WebSocket 31개)을 포함한다. 공식 가이드 변경에 따라 수와 내용은 달라질 수 있다.

## 2차 MVP: 국내 선물·옵션 백테스터

1차 단계에서 시세·차트·상품 마스터 API와 상품 필드를 확인한 뒤 과거 데이터 수집 및 정규화, 주문 시뮬레이션, 포지션·손익 계산을 구현한다. 옵션 만기 정산, 거래 비용, 증거금, 선물 롤오버는 공식 근거와 함께 모델링한다.

실계좌 주문 자동화는 백테스터 범위와 구분한다.
