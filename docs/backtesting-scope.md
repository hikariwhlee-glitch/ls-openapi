# 백테스트 범위

## 현재 동작

엔진은 한 종목의 OHLC 바를 시간순으로 받아 목표 보유 계약 수를 계산합니다. 바 종가까지의 정보로 생성한 신호는 다음 바 시가에서 체결합니다. 체결 가격은 설정한 틱 크기에 맞추고 슬리피지와 편도 수수료를 적용합니다. 마지막 보유분은 마지막 바 종가로 평가합니다.

CSV 입력 헤더: `timestamp,open,high,low,close`, 선택 항목 `volume`. timestamp는 ISO 8601이고 행은 시간 오름차순이어야 합니다.

## 다음 데이터 연동 단계

LS증권 공식 가이드에는 선물/옵션 일주월 차트 TR `t8466`가 있습니다. 초기 데이터 연동 후보는 일봉이며, 요청은 단축코드·주기·조회 건수·날짜 구간과 연속조회 값을 사용합니다. 어댑터는 아직 포함하지 않았습니다. 공식 스키마와 최신 버전은 [LS증권 TR 가이드 JSON](https://openapi.ls-sec.co.kr/api/apis/public/tr-guides.json?download=true)에서 확인합니다.

## 의도적으로 미지원

- 옵션 만기 정산, 행사·배정
- 거래소의 상품별 위탁/유지 증거금 및 옵션 조합 증거금
- 선물 월물 롤오버와 연속물 생성
- 호가 대기열, 부분 체결, 가격제한 처리
- LS API 시세 어댑터 및 자동 연속조회
- 실계좌 주문

현재의 고정 계약당 증거금 검사는 간단한 입력 검증일 뿐 실제 증거금 계산이 아닙니다. 실거래와 유사한 모델을 추가하기 전에 상품별 공식 규칙과 데이터 제공 범위를 검토해야 합니다.
