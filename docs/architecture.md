# 아키텍처

## 경계

- **시세 어댑터**: LS증권 API 또는 로컬 파일을 공통 OHLC 바 형식으로 변환한다. LS API 연동은 후속 단계다.
- **백테스트 코어**: 전략 신호, 주문, 체결, 포지션, 손익 및 지표 계산을 담당한다. 네트워크와 계정 인증에 의존하지 않는다.
- **전략**: 현재까지의 바를 입력으로 목표 수량을 반환한다. 외부 주문을 전송하지 않는다.
- **상품 설정**: 종목코드, 계약승수, 호가단위, 증거금 및 비용 설정을 보관한다.
- **리포트**: 전략과 데이터 기간, 계약 설정, 비용 및 체결 가정을 함께 표시한다.

## 현재 흐름

```text
로컬 OHLC CSV
      ↓
공통 OHLC Bar
      ↓
백테스트 코어
      ↓
거래 내역 + 자산 곡선
```

향후 LS API의 `t8466` 일봉 차트를 별도 어댑터 입력으로 연결한다. 실계좌 주문 기능은 백테스트 엔진과 분리한다.
