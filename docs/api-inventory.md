# API 목록과 확인 상태

이 저장소가 다루는 LS증권 OPEN API의 명세 확인 상태입니다.
기준 자료는 공식 포털의 [시작하기](https://openapi.ls-sec.co.kr/howto-use) 페이지와 포털이 제공하는 TR 명세 JSON(`ls-openapi-tr-guides.json`, 버전 `20261012053652748`)입니다.
다른 증권사의 명세는 적용하지 않았고, 서드파티 라이브러리·블로그에서 본 내용은 근거로 쓰지 않았습니다.

상태 표기: **확인** = 공식 자료에서 직접 확인, **실서버 확인** = 실제 서버를 호출해 동작을 확인(관측 일자와 조건 병기), **미확인** = 공식 자료로 확인하지 못함, **미검증** = 공식 자료에는 있으나 실서버로 동작을 확인하지 않음.

## 인증

### 접근토큰 발급 — 확인, 구현됨, 실서버 확인 (모의투자 키, 2026-10-12)

- `POST /oauth2/token`, `Content-Type: application/x-www-form-urlencoded`
- 요청 본문

| 필드 | 값 |
|---|---|
| `grant_type` | `client_credentials` 고정 |
| `appkey` | 포털에서 발급된 앱키 |
| `appsecretkey` | 포털에서 발급된 앱 시크릿키 |
| `scope` | `oob` 고정 |

- 응답 필드(실서버 확인): `access_token`, `expires_in`, `scope`(`oob`), `token_type`(`Bearer`). 유효기간 필드명은 `expires_in`입니다.
- "시작하기" 예시는 86400초(24시간)였지만 실제 응답의 `expires_in`은 46332초였습니다(1회 관측). 값이 고정이 아닐 수 있으니 하드코딩하지 말고 응답 값을 사용하세요.
- 구현: `src/ls_openapi/auth.py` (`issue_token`, `TokenManager`)

### 접근토큰 폐기 — 확인, 구현됨, 실서버 확인 (모의투자 키, 2026-10-12)

- `POST /oauth2/revoke`, `Content-Type: application/x-www-form-urlencoded`
- 요청 본문: `appkey`, `appsecretkey`, `token_type_hint`(`access_token` 또는 `refresh_token`), `token`
- 응답 필드(실서버 확인): `code`, `message`. 성공 시 `code`는 `200`, `message`는 "접근토큰 폐기에 성공하였습니다."였습니다(1회 관측). 실패 시의 `code` 값은 확인하지 않았고, 코드는 응답을 해석하지 않고 그대로 반환합니다.
- 구현: `src/ls_openapi/auth.py` (`revoke_token`, `TokenManager.revoke`)

## TR 호출 공통 규칙 — 확인, 구현됨 (`t2111` 모의투자 실서버 확인)

공식 가이드 JSON 버전 `20261012053652748`에서 국내선물 시세 및 주문 TR의 경로·요청 형식도 확인했습니다. 세부 필드는 TR별 문서를 참고하세요.

| 항목 | 내용 |
|---|---|
| 메서드 | `POST` (명세의 기본값) |
| 요청 헤더 | `content-type`(`application/json; charset=utf-8`), `authorization`(접근토큰), `tr_cd`(거래 코드), `tr_cont`(연속 여부 `Y`/`N`), `tr_cont_key`(연속 키), `mac_address`(법인만 필수) |
| 요청 본문 | `{"<TR코드>InBlock": {...}}` |
| 응답 헤더 | `tr_cd`, `tr_cont`, `tr_cont_key` |
| 응답 본문 | `<TR코드>OutBlock`, `<TR코드>OutBlock1` 등 (TR마다 다름) |

- 구현: `src/ls_openapi/client.py` (`LSClient.post_tr`, `build_in_block`). 개별 API(TR 코드, 경로)는 들어 있지 않습니다.
- 토큰 응답의 `token_type`은 실서버에서 `Bearer`로 확인했습니다. `authorization: Bearer <토큰>` 호출도 `t2111` 모의투자 실서버에서 확인했습니다 (2026-10-14). 다른 TR의 동작까지 확인한 것은 아닙니다.

## 선물/옵션 현재가(시세)조회 `t2111` — 구현·모의투자 실서버 확인

근거: 공식 가이드 JSON 버전 `20261012053652748`에서 경로, 요청·응답 스키마, 호출 제한을 확인했습니다. 모의투자 실서버에서는 8자리 코드만 유효 데이터가 반환되고, 네 월물 조회를 확인했습니다.

| 항목 | 내용 | 상태 |
|---|---|---|
| API명 | 선물/옵션현재가(시세)조회 | 확인 (공식 API 서비스 페이지) |
| 엔드포인트 | `POST https://openapi.ls-sec.co.kr:8080/futureoption/market-data` | 샘플 기반 구현, 모의투자 실서버 호출 성공 (2026-10-14) |
| 요청 헤더 | `content-type`(`application/json; charset=utf-8`), `authorization`(`Bearer <토큰>`), `tr_cd`(`t2111`), `tr_cont`(`N`), `tr_cont_key`(빈 문자열) | 샘플 기반, 실서버 호출 성공 |
| 요청 본문 | `{"t2111InBlock": {"focode": "<종목코드>"}}` | 샘플 기반, 실서버 호출 성공 |
| `focode` | 8자리 종목코드가 맞습니다. | **실서버 확인** (모의투자 키, 2026-10-14) |
| 현재 상장 네 월물 | `A016C000` (코스피200 F 202612), `A0173000` (202703), `A0176000` (202706), `A0179000` (202709) — 네 코드 모두 반환 `focode`가 요청과 일치하고 시세 응답 성공 | **실서버 확인** (Actions 재실행, 2026-10-14) |

| 응답 구조 | 최상위 `rsp_cd`, `rsp_msg`, `t2111OutBlock`. 성공 응답은 `rsp_cd=00000`, `rsp_msg=조회완료`; OutBlock에 요청 종목코드와 시세 필드가 포함됩니다. | **실서버 확인** (모의투자 키, 2026-10-14) |
| 연속조회 응답 헤더 | `tr_cd=t2111`, `tr_cont=N`, `tr_cont_key=0` | **실서버 확인** (모의투자 키, 2026-10-14) |
| 응답 필드 의미·자료형 | 공식 `t2111OutBlock` 71개 필드의 한국어 명칭·자료형·길이 정리 | 명세 확인; [필드 문서](t2111-fields.md) |
| 초당 호출 제한 | 공식 가이드 기준 초당 10회 | 명세 확인; 실서버 제한 별도 확인 안 함 |
| 종목코드 조회 | 코스피200 등 지수선물 마스터 `t8467` 구현. 응답은 실서버 미검증 | 명세 확인·구현 |

- 구현: `src/ls_openapi/tr/market_data/t2111.py`의 `fetch_current_price(client, focode)`. 응답은 해석하지 않고 서버가 준 JSON을 `TRResponse.body`에 그대로 담습니다.
- 검증 방식: 모의투자 키로 실서버를 호출했고, 요청한 `focode`가 OutBlock에 동일하게 반환되고 `rsp_cd=00000`인 경우만 성공으로 봤습니다. 자동 테스트 코드는 저장소에서 제거했습니다.
- 최신 검증: 2026-10-14 모의투자 실서버 호출에서 현재 상장 네 코드(`A016C000`, `A0173000`, `A0176000`, `A0179000`) 모두 `rsp_cd=00000` 및 요청과 일치하는 `t2111OutBlock.focode`를 반환했습니다. 5자리 `A016C`는 데이터 없는 응답이었습니다.
- 예제: `examples/domestic_futureoption/02_futures_price.py <종목코드>` (발급 → 조회 → 폐기).

## 추가 시세 TR — 명세 확인·구현, 실서버 미검증

- `t2112` 선물/옵션 현재가 호가 조회: `POST /futureoption/market-data`, 8자리 `shcode`, 초당 10회. 모듈 `market_data/t2112.py`, 문서 [시세 TR](market-data.md).
- `t8467` 지수선물 마스터: 같은 경로, `gubun`으로 상품군 선택, 초당 2회. 일반 코스피200 선물은 공식 설명상 V/S/Q 외 값을 사용합니다. 모듈 `market_data/t8467.py`.
- `t8435`는 미니·위클리 등 별도 파생 상품군 마스터이므로 일반 코스피200 월물 선택 용도로 사용하지 않습니다.
- 두 구현 모두 공식 JSON 스키마 기반이며 응답은 원본 JSON입니다. 실서버 확인은 아직 하지 않았습니다.

| 시세 호출 예시 | "시작하기"의 주식 현재가 예시는 `GET`, 헤더 `tr_id` 사용. TR 명세 JSON은 `POST`, 헤더 `tr_cd` | TR 명세 JSON을 기준으로 삼음. 예시 코드는 따르지 않음 |

## 실시간 선물 시세 WebSocket — 구현, 실서버 검증 대기

- 공식 도메인: 모의투자 `wss://openapi.ls-sec.co.kr:29443/websocket`, 실전 `wss://openapi.ls-sec.co.kr:9443/websocket`.
- `header.token`에 Access Token, `header.tr_type=3`으로 시세 구독을 등록하고 `tr_type=4`로 해제합니다.
- `FC9` KOSPI200 선물 체결, `FH9` KOSPI200 선물 호가를 구현했습니다. 각각 사용자가 검증한 8자리 월물 코드를 받습니다.
- 구현: `src/ls_openapi/websocket.py`, 예제: `examples/domestic_futureoption/04_futures_realtime.py`. 모의투자 서버가 기본값이며 `--live`를 지정해야 실전 서버를 선택합니다.
- 장중 모의투자 연결, 구독 승인 응답, 데이터 수신은 아직 확인하지 않았습니다. 프레임 및 공식 필드 목록은 [WebSocket 문서](websocket.md)를 참고하세요.

## 선물/옵션 정상주문 `CFOAT00100` — 구현·모의투자 주문 접수 확인

공식 포털은 `POST /futureoption/order`, TR `CFOAT00100`(선물옵션 정상주문), 초당 전송 10회를 안내합니다. [공식 주문 API 가이드](https://openapi.ls-sec.co.kr/apiservice?api_id=b579d38a-3ce5-4b1b-b94e-b0c4bbbf1d27&group_id=2f1eea77-5606-4512-93c6-31b21d2ece90). 요청 필드 상세는 포털에서 확인 시 표시되지 않아, 필드 형식은 사용자가 제공한 호출 샘플을 기준으로 했습니다.

| 항목 | 내용 | 상태 |
|---|---|---|
| TR / 경로 | `CFOAT00100`, `POST /futureoption/order` | 공식 포털에서 확인 |
| 요청 블록 | `CFOAT00100InBlock1` | 사용자 제공 샘플 기준 |
| 입력 필드 | `FnoIsuNo`, `BnsTpCode`, `FnoOrdprcPtnCode`, `FnoOrdPrc`, `OrdQty` | 샘플 기준, 매매·호가 코드표는 미확인 |
| 응답 | 모의투자에서 `rsp_cd=00040`, “모의투자 매수주문이 완료 되었습니다.” 관측 | 접수 성공으로 관측; 환경별 의미 일반화는 미확인 |
| 검증 | 8자리 월물 네 종목에 각 1계약 매수 요청, 성공 접수 응답 확인 | 모의투자 실서버, 2026-10-14; 체결 여부는 별도 |

- 구현: `src/ls_openapi/tr/orders/CFOAT00100.py`의 `submit_futures_option_order`. 사용자가 넘긴 가격·수량·코드로 주문 TR만 호출하며 현재가 조회, 틱 계산, 매매 결정 로직은 포함하지 않습니다.
- 예제: `examples/domestic_futureoption/03_futures_option_order.py`. 명령행에서 종목·코드·가격·수량을 직접 지정합니다.
- 주문 요청은 자동 재시도하지 않습니다. 함수 사용법과 제한은 [docs/orders.md](orders.md)를 참고하세요.
## 정정·취소 주문

- `CFOAT00200` 정정주문과 `CFOAT00300` 취소주문은 공식 가이드 JSON에서 `POST /futureoption/order`, 초당 10회, 입력 필드와 길이를 확인하고 기능 모듈을 구현했습니다.
- 구현: `src/ls_openapi/tr/orders/CFOAT00200.py`, `CFOAT00300.py`. 샘플 기반 요청 호출이며 실서버 미검증입니다.
- 요청 필드와 실행 예시는 [주문 문서](orders.md)를 참고하세요. 예제: `05_modify_order.py`, `06_cancel_order.py` (정상주문 `03` 예제의 `--show-response`로 원주문번호를 확인).
