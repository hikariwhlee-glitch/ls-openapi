# ls-openapi

LS증권 Open API의 **국내 선물·옵션 공식 명세를 수집하고 정리하는 저장소**입니다.

## 1차 MVP — 공식 명세 수집

현재 범위는 LS증권 공식 가이드에서 국내 `선물/옵션` 카테고리에 속한 명세를 가져와 보존·정리하는 것입니다. 최신으로 생성된 스냅샷은 공식 가이드 버전 `20261012053652748` 기준 **7개 API 그룹, 91개 TR**을 포함합니다. 시세, 차트, 투자자, 계좌, 주문, 기타, 실시간 시세 명세가 포함됩니다.

- [사람이 읽는 전체 명세](docs/domestic-futures-options.md)
- [전체 API 명세 JSON 스냅샷](specs/domestic-futures-options.json)
- [공식 가이드 원본](https://openapi.ls-sec.co.kr/api/apis/public/tr-guides.json?download=true)

## 명세 다시 가져오기

Python 3.9 이상이 필요하며 외부 라이브러리는 사용하지 않습니다.

```bash
python scripts/sync_official_specs.py
```

스크립트는 공식 JSON에서 `선물/옵션` 카테고리 전체를 추출해 JSON 스냅샷과 Markdown 문서를 다시 생성합니다. 생성 결과를 검토한 뒤 커밋하면 최신 공식 가이드 버전으로 갱신됩니다.

## 2차 MVP — 백테스터

백테스터는 2차 MVP입니다. 1차에서 명세와 데이터 형식을 파악한 뒤, 상품별 과거 데이터와 계약 정보를 이용하는 백테스트 코어를 설계합니다. 1차 범위에는 인증, 실시간 호출, 주문 실행, 백테스터 구현이 포함되지 않습니다.

## 출처 및 안내

이 저장소는 LS증권과 무관한 비공식 개인 프로젝트입니다. 명세의 출처는 LS증권 OPEN API 공식 가이드입니다. 공식 가이드와 저장소 문서가 다르면 공식 가이드를 기준으로 확인하세요.
