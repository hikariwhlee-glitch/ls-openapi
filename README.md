# ls-openapi

LS증권 Open API 시세를 활용해 국내선물옵션 백테스터를 만드는 공개 프로젝트입니다.

기존 저장소 구성을 정리하고 백테스트 코어부터 다시 시작합니다. 현재 코어는 로컬 OHLC CSV로 실행됩니다. LS API 인증과 과거 시세 연결은 별도 단계로 추가합니다.

## 목표

- LS증권 국내 파생 시세를 공통 데이터 형식으로 받아 백테스트한다.
- 전략 신호, 주문 체결, 포지션, 손익 계산을 API 호출과 분리한다.
- 체결 비용과 상품별 계약 설정을 명시적으로 관리한다.
- 결과와 함께 데이터 기간 및 모델 가정을 기록한다.

## 현재 구현

- 로컬 OHLC CSV 입력과 시간순서 검증
- 다음 바 시가 체결의 단일 종목 시뮬레이션
- 수수료, 슬리피지, 계약승수 및 고정 증거금 한도
- 거래 내역, 평가자산 곡선, 총수익률, 최대낙폭 계산

## 빠른 시작

Python 3.9 이상:

```bash
python -m pip install -e .
python examples/backtest_csv.py examples/sample_futures_1m.csv \
  --symbol SAMPLE-FUT --multiplier 1 --tick-size 0.01 --margin 0 --fee 0
```

샘플 시세와 인자는 형식 시연용 임의 값이며 실제 시장 데이터나 계약 조건이 아닙니다.

입력·체결 규칙과 미지원 범위는 [백테스트 범위](docs/backtesting-scope.md), 구성은 [아키텍처](docs/architecture.md)를 참고하세요.

## 다음 단계

1. LS API 인증·공통 TR 클라이언트 경계를 추가한다.
2. 공식 가이드의 선물/옵션 일봉 차트 `t8466`를 시세 어댑터로 구현하고 응답을 검증한다.
3. 분봉·옵션 시계열과 상품 명세를 추가한다.
4. 옵션 만기 정산, 증거금, 선물 롤오버 모델을 실제 상품 규칙에 맞춰 확장한다.

## 주의

이 코드는 연구·교육용입니다. 옵션 만기 정산, 행사·배정, 거래소 증거금, 월물 롤오버, 호가 잔량 기반 체결을 모델링하지 않습니다. 투자 조언이나 실거래 손익 예측으로 사용하지 마세요. 실제 승수·틱·수수료·증거금은 LS증권 및 거래소의 최신 상품 명세를 확인해야 합니다.

- LS증권 OPEN API 공식 포털: https://openapi.ls-sec.co.kr/
- 이 프로젝트는 LS증권과 무관한 비공식 개인 프로젝트입니다.
